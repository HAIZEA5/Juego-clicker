# Savia

Juego idle y de clics: cosecha frutos de un árbol en un claro del bosque, consigue amuletos y llaves rúnicas, cruza el portal y asciende al cielo.

Se juega en el navegador del móvil y funciona sin conexión. Para instalarlo en el iPhone: abre la página en Safari → Compartir → **Añadir a pantalla de inicio**.

La partida se guarda solo en el dispositivo. Para pasarla a otro sitio: **Diario → Ajustes → Copiar código de partida**.
